# 神经寻路（NeuroJump）

安卓平台上的 2D 平台跳跃游戏：**AI 从零开始，用遗传算法学会跑酷**。

应用运行时在后台并行训练神经网络，屏幕上实时显示 AI 在关卡里的表现。
没有预设行为、没有示教数据——只有「跳得远就留下后代」这一个规则。

## 玩法

| 模式 | 说明 |
|---|---|
| 课程训练（100 层） | 逐层引入水平移动平台、垂直移动平台、尖刺 |
| 无限训练 | 层数无上限，难度约 60 层后饱和 |
| 无限跑分 | 永无尽头的横向跑酷，按跑出的距离进化 |
| 卡点训练 | 整条跑酷全是移动平台，专练「起跳时机」 |
| 竞速演进 | 多个族群的模型同场竞速，按名次择优交叉繁殖下一代 |
| 手动试玩 | 玩家自己上手，和 AI 用同一套物理 |

## 技术实现

- **网络**：`29 → 40 → 20 → 3` 全连接，tanh 激活，扁平权重便于遗传算法直接交叉变异
- **进化**：锦标赛选择 + 分段交叉 + 自适应变异 + 精英保留 + 历史最佳重注入
- **物理**：加速度移动、二段跳、土狼时间、跳跃缓冲、单向平台、移动平台携带、空中箱子连跳
- **关卡自检**：课程关每层生成后都用真实物理做可达性验证，保证 100 层全部可通关
- **并行**：评估线程池按 CPU 核数展开，UI 只读 volatile 快照，不阻塞渲染

## 输入特征（29 维）

自身状态 6 · 前方地形 8 · 落脚点 4 · 移动平台时序 6 · 跳跃可行性 3 · 危险 2

移动平台的两项时间窗口量（还要等多久平台才摆到最佳落点、那时它离你多远）
是让 AI 学会「卡点起跳」的关键。

## 构建

本地需 JDK 17 + Android SDK（compileSdk 34）：

```bash
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
./gradlew :android:assembleRelease
```

产物在 `android/build/outputs/apk/release/`。

仓库也带了 GitHub Actions 配置，推送后会自动构建并上传 APK 产物。

## 项目结构

```
core/      纯 Java 游戏逻辑（无图形依赖，可离线跑基准测试）
  nn/      多层感知机
  train/   遗传算法、训练器、传感器、奖励
  world/   物理、关卡生成、可达性校验
  race/    竞技场与竞速个体
  store/   模型存档（基因 + 族谱）
  ui/      渲染与控件
android/   Android 壳（minSdk 21，arm64-v8a + armeabi-v7a）
tools/     基准测试与打包脚本
```

## 开发基准

`tools/Bench2.java` 是改动网络结构或训练参数后的统一评测口径：
固定训练时长，测「从起点起跑」的最远距离，附 20 次重复以确认可复现性。

> 改完务必跑一次：这个项目的训练结果曾经依赖多线程调度顺序，
> 同一个程序两次运行能差出 40%。现在已修复，但回归测试仍要靠它。
